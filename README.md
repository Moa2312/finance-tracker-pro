# 💰 VIP Financial Tracker - PRO

A responsive, client-side financial tracking tool built with HTML, CSS, and vanilla JavaScript. Designed for quick, secure budget management with a sleek dark-mode UI.

## ✨ Features
* **Responsive Design:** Mobile-first layout optimized for all screen sizes.
* **Dynamic Tracking:** Real-time calculation of Income, Expenses, and Total Balance.
* **Security Module:** Built-in auto-lock and PIN protection for privacy.
* **Data Persistence:** Uses LocalStorage to save records safely on your device.
* **Export Capability:** Export your financial history to a CSV file in one click.

## 🚀 Tech Stack
* HTML5
* CSS3 (Custom Variables, Flexbox, Grid)
* Vanilla JavaScript

## 🛠️ Getting Started
Since this is a lightweight client-side utility, simply open `index.html` in any modern web browser to start managing your finances locally.
